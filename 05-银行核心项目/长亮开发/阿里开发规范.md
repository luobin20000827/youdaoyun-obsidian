## OOP规范
1. .equals()调用方不能为null，不然会抛出NPE;
    - 一般用确定的字符/变量来调用.equals()
    - 更进一步，用java7中引入的Object.equals(a,b)来判断
2. 所有包装类必须用equals，不能用==
    - Pojo的成员变量必须用包装类
    - RPC方法参数和返回值必须用包装类
3. 构造方法里面禁止加入任何业务逻辑，如果有初始化逻辑，请放在 init 方法中。
4. 循环体内，字符串的连接方式，使用 StringBuilder 的 append 方法进行扩展。
5. 深浅copy
6. 只有需要与继承类交互的成员变量/方法用protected装饰，其他都用private

## 集合数据对象规范
1.ArrayList数组和List的互转

- List2Array：list.toArray(T[] array) 这里T[] array要传一个list.size()类型的泛型变量,否则返回Object[]对象再强转会出问题
    
    
```
List<String> list = new ArrayList<String>(2);
list.add("guan");
list.add("bao");
String[] array = new String[list.size()];
array = list.toArray(array);

```

- Array2List：Arrays.asList()
```
String[] array = {"a","b","c"};
List list = Arrays.asList(array);
```
