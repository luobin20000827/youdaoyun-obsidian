- 代码生成器就是一个前后端不分离的springboot系统
- 运行jar包之后，8079端口启动
- 实现了类似神码平台数据表模型管理的功能，
- 根据系统中建好的书库自动生成数据模型层（ihelpdomain接口）和数据访问层的代码（orm部分）的代码
    - 管理类系统也可以使用一并生成的业务逻辑层和控制器层，满足简单的增删改查操作
    - 生成使用vue/element-ui版前端的数据库管理界面


- 前端的代码生成器
 - api一般是放module下面的
 - router 全局的
 - index view文件
- 前端初始化框架就是带有monitoring flow和config



- 前端项目 
    - npm run template-ui这个项目


- dao层的mapper和里面的动态查询是参考mybatis-generator里面的criteria和example写的，help文档里有示范，其中example的criteria默认是以and连接的，他还有一个特别的属性or(),里面构筑的条件都是以or连接的

- 前端要记得配置镜像
