# 8.22
- 遇到一个build时的问题：win7会遇到一个os_uv_hostname缺失的问题，可以查看log里面报错的文件进去添加一行参数
- dev和build会遇到版本问题，package.json里面有的可以去改package里面的配置，不行就npm --install -save @版本号
- nexus端 read就是拉取权限
    - 关闭匿名访问之后，后端maven setting里面的server_id, mirror_id以及根pom中的profile_id都要保持一致（我们现在的设置中都可以设置为developer developer）；
    - 前端则要npm login（developer developer developer@jsnx.com）然后设置 npm config set registry "镜像地址"
