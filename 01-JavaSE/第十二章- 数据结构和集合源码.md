### 12.1.2 基于代码实现：List接口分析
1. 动态数组ArrayList和Vector
- 两者扩容机制不同，前者默认扩容为原来的1.5倍，后者则为两倍
- 初始化容量不同，JDK8.0后，ArrayList再添加第一个元素时才创建长度为10的数组，而Vector一直为10
- 线程安全不同：前者线程不安全，后者线程安全


2. LinkedList
- LinkedList对象本身有头尾指针，而每个Node又有pre和next属性
- list.add("AA"):将aa封装到一个Node1对象内,list对象的first,last都指向Node1
- list.add("BB"):将aa封装到一个Node2对象内,对象1和对象2组成一个双向链表，此时last指向Node对象2
- LinkedList不需要考虑扩容问题

3.启示
- Vector基本已经不用
- 查找，添加vs插入
- 开发中大体确定数组长度的情况ArrayList(capacity = xx)



## 12.2 树
- 基本概念：：
    - 结点
        - 根节点
        - 父节点
        - 子节点
        - 叶节点
        - 兄弟节点
    - 度数：节点度数就是其拥有的子树个数
    - 深度：最大层次数
    - 层数：从根节点到树中某结点所经路径上的分支树称为该结点的层数，根节点的层数规定为1，其余结点的层数等于其父亲结点的层数+1

### 12.2.1 二叉树概念
- 每个节点最多存储两颗子树的树
- 二叉树的遍历（根的位置）

    - 中序：左根右

1. 满二叉树
- 除最后一层无任何子节点外，每一层上的所有结点都有两个子结点的二叉树。
- 第n层的结点数是2的n-1次方，总的结点个数是2的n次方-1
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC14%E7%AB%A0_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E4%B8%8E%E9%9B%86%E5%90%88%E6%BA%90%E7%A0%81/images/1574575163883-1661447692846.png)
2. 完全二叉树
- 除了最后一层外都完全填充了节点
- 且最后一层的叶节点是从左到右填充的
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC14%E7%AB%A0_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E4%B8%8E%E9%9B%86%E5%90%88%E6%BA%90%E7%A0%81/images/1574575180247-1661447692846.png)
3. 二叉排序/查找/搜索树 BST (binary search/sort tree)
- 若它的左子树不为空，则左子树上所有结点的值均小于它的根节点的值； 
- 若它的右子树上所有结点的值均大于它的根节点的值； 
- 它的左、右子树也分别为二叉排序/查找/搜索树。
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC14%E7%AB%A0_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E4%B8%8E%E9%9B%86%E5%90%88%E6%BA%90%E7%A0%81/images/image-20220521145208018.png)
4. 平衡二叉树（Self-balancing binary search tree，AVL）
- 首先平衡二叉树是一颗特殊的二叉排序树
- 除此之外，他的左右两子树的高度差不超过1
- 他的左右子树也是一颗平衡二叉树

5 红黑树
- 红黑树也是一种近似平衡的二叉搜索树
- 它在AVL树的基础上增加了节点颜色标记（红色和黑色）
- 叶黑根黑，红子必黑，黑高相等

## 12.3 Map接口

### 12.3.1 物理结构
- HashMap和Hashable底层都是哈希表，在java中，他们是由数组+链表+红黑树 组成的
- 他的底层是一个名为table的数组，里面存储着Entry(Java8中称为Node)
- 当我们调用 put(K key, V value) 方法时，会计算 key 的哈希值，并确定它在 table 数组中的位置。如果该位置还没有别的节点，那么就把这个新的键值对放进去。如果已经有别的节点，那么会形成链表或者红黑树（碰撞的node超过阈值（默认为8）且数组长度超过64，转换为红黑树以提高查询效率，少于6则退回链表）。
`transient Node<K,V>[] table;`
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC14%E7%AB%A0_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E4%B8%8E%E9%9B%86%E5%90%88%E6%BA%90%E7%A0%81/images/image-20221029144811305.png)

### 12.3.2 Node
- 在jdk1.8之后，key-value键值对都被封装在HashMap.Node类型或HashMap.TreeNode类型，它俩都直接或间接的实现了Map.Entry接口。
- ![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC14%E7%AB%A0_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84%E4%B8%8E%E9%9B%86%E5%90%88%E6%BA%90%E7%A0%81/images/image-20220514190904009-1661448231966.png)
- 加载因子：用来衡量HashMap何时需要进行扩容（rehash）。当HashMap的实际大小（元素数量）超过了阈值（threshold），那么HashMap就会进行扩容。阈值等于容量(capacity)乘以加载因子(load factor)，
- 初始容量：在无参构造器中为16，也可以通过initialCapacity设置一个（实际上会取最近的2^x，便于hash寻址）
- 在jdk8之后，如果要在链表上添加新数据使用的是尾插法（防止多线程情况下的死循环等问题）

```
public class HashMap<K,V>{
    transient Node<K,V>[] table;
    
    //Node类
    static class Node<K,V> implements Map.Entry<K,V> {
        final int hash;
        final K key;
        V value;
        Node<K,V> next;

        Node(int hash, K key, V value, Node<K,V> next) {
            this.hash = hash;
            this.key = key;
            this.value = value;
            this.next = next;
        }
        // 其它结构：略
    }
    
    //TreeNode类
    static final class TreeNode<K,V> extends LinkedHashMap.Entry<K,V> {
        TreeNode<K,V> parent;
        TreeNode<K,V> left;
        TreeNode<K,V> right;
        TreeNode<K,V> prev;//准备退化为链表
        boolean red; //是红结点还是黑结点
        TreeNode(int hash, K key, V val, Node<K,V> next) {
            super(hash, key, val, next);
        }
    }
    
    //....
}
```
