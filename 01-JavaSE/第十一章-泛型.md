# 第十一章-泛型

## 11.1 泛型的理解
- 泛型就是类型参数，在声明它的类、接口与方法中代表某种通用类型
- 不使用泛型，在传入数据时我们都把他看作Object，后续操作时都需要做强转
- 在使用泛型之后，我们在编译这一环节就保证了传入的数据是我们想要的类型，使代码更加简洁、健壮

```
//泛型在Map中的使用
@Test
public void test2(){
    HashMap<String,Integer> map = new HashMap<>();

    map.put("Tom",67);
    map.put("Jim",56);
    map.put("Rose",88);
    //编译不通过
    //        map.put(67,"Jack");

    //遍历key集
    Set<String> keySet = map.keySet();
    for(String str:keySet){
        System.out.println(str);
    }

    //遍历value集
    Collection<Integer> values = map.values();
    Iterator<Integer> iterator = values.iterator();
    while(iterator.hasNext()){
        Integer value = iterator.next();
        System.out.println(value);
    }

    //遍历entry集
    Set<Map.Entry<String, Integer>> entrySet = map.entrySet();
    Iterator<Map.Entry<String, Integer>> iterator1 = entrySet.iterator();
    while(iterator1.hasNext()){
        Map.Entry<String, Integer> entry = iterator1.next();
        String key = entry.getKey();
        Integer value = entry.getValue();
        System.out.println(key + ":" + value);
    }

}
    }
}
```


## 11.2 使用泛型举例

### 11.2.1 集合中的泛型

- 在实例化集合对象时
    - 如果没有使用泛型，则认为操作的都是Object
    - 如果使用了泛型，则需要指明泛型的基本类型，一旦指明了泛型的具体类型，则在集合的相关方法中，凡是使用了类泛型的位置，都替换为具体的泛型类型。

- 没有使用泛型时
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC13%E7%AB%A0_%E6%B3%9B%E5%9E%8B/images/image-20220411001522636.png)
- 使用泛型时
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC13%E7%AB%A0_%E6%B3%9B%E5%9E%8B/images/image-20220411001549747.png)

- 注意：在集合内重写equals()不要使用泛型
    - 该方法重写的是Object父类中的equals(),若使用泛型则新重写的equals()就不再被认为是Object中的equals方法，那么后面在对象被当作Object类型处理的时候就会出问题（例如多态等情况）

```
//泛型在Map中的使用
@Test
public void test2(){
    HashMap<String,Integer> map = new HashMap<>();

    map.put("Tom",67);
    map.put("Jim",56);
    map.put("Rose",88);
    //编译不通过
    //        map.put(67,"Jack");

    //遍历key集
    Set<String> keySet = map.keySet();
    for(String str:keySet){
        System.out.println(str);
    }

    //遍历value集
    Collection<Integer> values = map.values();
    Iterator<Integer> iterator = values.iterator();
    while(iterator.hasNext()){
        Integer value = iterator.next();
        System.out.println(value);
    }

    //遍历entry集
    Set<Map.Entry<String, Integer>> entrySet = map.entrySet();
    Iterator<Map.Entry<String, Integer>> iterator1 = entrySet.iterator();
    while(iterator1.hasNext()){
        Map.Entry<String, Integer> entry = iterator1.next();
        String key = entry.getKey();
        Integer value = entry.getValue();
        System.out.println(key + ":" + value);
    }
}
```

### 11.2.2 比较器中使用泛型
- 自然排序(Comparable接口-compareTo())

```
public class Rectangle implements Comparable<Rectangle> {
    private int width;
    private int length;

    public int getArea(){
        return width*length;
    }

    public int getCircumference(){
        return 2*(width+length);
    }


    @Override
    public int compareTo(Rectangle o) {
        return (this.getArea() - o.getArea()==0) ? this.getCircumference()-o.getCircumference() :this.getArea() - o.getArea();
    }
}
```



- 定制排序(Comparator类,compare())

```
package com.atguigu.generic;

import java.util.Comparator;

class CircleComparator1 implements Comparator<Circle> {

    @Override
    public int compare(Circle o1, Circle o2) {
        //不再需要强制类型转换，代码更简洁
        return Double.compare(o1.getRadius(), o2.getRadius());
    }
}

//测试类
public class TestHasGeneric {
    public static void main(String[] args) {
        CircleComparator1 com = new CircleComparator1();
        System.out.println(com.compare(new Circle(1), new Circle(2)));

        //System.out.println(com.compare("圆1", "圆2"));
        //编译错误，因为"圆1", "圆2"不是Circle类型，是String类型，编译器提前报错，
        //而不是冒着风险在运行时再报错。
    }
}
```

## 11.3 自定义泛型结构

- 泛型参数在指明时，只能使用引用数据类型（基本数据类型-包装类）

### 11.3.1 自定义泛型类/接口
- 声明类或接口时，在类名或接口名后面声明泛型类型，我们把这样的类或接口称为泛型类或泛型接口。
- 
```
【修饰符】 class 类名<类型变量列表> 【extends 父类】 【implements 接口们】{
    
}
【修饰符】 interface 接口名<类型变量列表> 【implements 接口们】{
    
}

//例如：
public class ArrayList<E>    
public interface Map<K,V>{
    ....
}    
```
- 在定义泛型类/接口之后，我们就可以在内部们在声明完自定义泛型类以后，可以在类的内部（比如：属性、方法、构造器中）使用类的泛型。

```
- 很多时候，当我们在类或接口中定义某个成员时，该成员的相关类型是不确定的，而这个类型需要在使用这个类或接口时才可以确定，那么我们可以使用泛型类、泛型接口
- 也可以把他理解为占位符，这些占位符在实例化类或者实现接口的时候，会被具体的类型替代。
```
- 有继承关系的情况下

```
class Father<T1, T2> {
}
// 子类不保留父类的泛型
// 1)没有类型 擦除
class Son<A, B> extends Father{//等价于class Son extends Father<Object,Object>{
}
// 2)具体类型
class Son2<A, B> extends Father<Integer, String> {
}
// 子类保留父类的泛型
// 1)全部保留
class Son3<T1, T2, A, B> extends Father<T1, T2> {
}
// 2)部分保留
class Son4<T2, A, B> extends Father<Integer, T2> {
}

```
- 在实例化泛型对象时，如果不注明泛型类型，泛型就被擦除了（可以理解为于Object o，但不等价）
    


### 11.3.2 自定义泛型方法

- 如果我们定义类、接口时没有使用<泛型参数>，但是某个方法形参类型不确定时，这个方法可以单独定义<泛型参数>。
- 
```
[访问权限]  <泛型>  返回值类型  方法名([泛型标识 参数名称])  [抛出的异常]{
    
}
```
- 方法可以被泛型化与其所处的类是否是泛型类没有关系;与其本身是否静态也没有关系

```
/**
 * @author 尚硅谷-宋红康
 * @create 9:11
 */
public class Exer01 {

	//编写一个泛型方法，接收一个任意引用类型的数组，并反转数组中的所有元素
    public static <E> void method1( E[] arr){
        for(int min = 0,max = arr.length - 1;min < max; min++,max--){
            E temp = arr[min];
            arr[min] = arr[max];
            arr[max] = temp;
        }
    }

    @Test
    public void testMethod1(){
        Integer[] arr = new Integer[]{10,20,30,40};
        method1(arr);
        for(Integer i : arr){
            System.out.println(i);
        }
    }
}
```

## 11.4 泛型在继承上的体现

- 不可协变：A是B的子类，但`G<A>`并不是`G<B>`的子类
    - 装苹果的篮子不是装水果篮子的子类，如果是的话，我们就能往这个篮子里装香蕉，因为向上转型是合法的

```
List<String> stringList = new ArrayList<>();
List<Object> objectList = stringList;  //这一行会引起编译错误
```

## 11.5 通配符

- 当我们声明一个变量/形参时，这个变量/形参的类型是一个泛型类或泛型接口，例如：Comparator类型，但是我们仍然无法确定这个泛型类或泛型接口的类型变量的具体类型，此时我们考虑使用类型通配符 ? 

### 11.5.1 通配 符的格式
- 类型通配符：?
- 比如：List<?>，Map<?,?>

```
List<?>是List<String>、List<Object>等各种泛型List的父类。
```
### 11.5.2 通配符的读与写
- 对于使用通配符的类，写入元素是不安全的
- 
```
Collection<?> c = new ArrayList<String>();

c.add(new Object()); // 编译时错误
```
- 但是读是安全的 

```
Collection<?> c = new ArrayList<String>();

System.out.println(c.get(0))
```

### 11.5.3 有限制条件的通配符
- List<? extends A> 可以将List<B>赋给List<? extends A>，B是A类的子类（使用时指定的类型必须是继承某个类，<=）
- List<? super A> 可以将List<B>赋给List<? super A>，B是A类的父类（使用时指定的类型必须是操作的类或接口，或者是操作的类的父类或接口的父接口,>=）

### 11.5.4 使用注意点
- 区别泛型方法：泛型方法是在返回值类型前加<>的方法，而不是在返回值类型中加入泛型的方法
- 通配符不能用在泛型类声明上

```
class GenericTypeClass<?>{
}
```
