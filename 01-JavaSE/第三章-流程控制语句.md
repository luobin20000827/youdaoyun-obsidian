# 第三章 流程控制语句
## 1. 分支语句
* 基本格式：
```
if (条件表达式){
    语句块1;
} 
```
* 双分支

```
if (条件表达式){
    语句块1;
} else{
    语句块2;
}
```
* 多分支
```
if (条件表达式1){
    语句块1;
} else if (条件表达式2){
    语句块2;
}
.....
}else if (条件表达式i){
    语句块i;
} else{
    语句块i+1;
}
```
* `if...else`是顺序执行的，因此当条件表达式之间存在交集时需要注意顺序
* 可以嵌套

## 2. 使用Scanner实现键盘输入
* 导包：`import java.util.Scanner`
* 创建Scanner对象：`Scanner scan = New Scanner(System.in)`
* 调用方法：`String`对应`scan.next()`;其他数据类型对应`scan.nextXXX()`
* 释放资源`scan.close()`


## 3.如何获得一个随机数
* 使用math中的random类，返回一个[0,1)之间的double值:`Math.random`
* 要取[a，b]，即`Math.random()*(b-a+1)+a`

## 4.Switch-case选择结构
* 语法结构：
```
switch(表达式){
    case 常量1:
        语句块1;
        //break
    case 常量2:
        语句块2;
        //break
        ......
    case 常量n:
        语句块n;
        //break
    default:
        System.out.println("others")
}
```
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC03%E7%AB%A0_%E6%B5%81%E7%A8%8B%E6%8E%A7%E5%88%B6%E8%AF%AD%E5%8F%A5/images/image-20220514101841710.png)
* 表达式的值必须时一下几种类型之一：`byte，short，char，int，枚举 (jdk 5.0)，String (jdk 7.0)；`
* case子句中的值必须是常量，不能是变量名或不确定的表达式值或范围
* 同一个switch语句，所有case子句中的常量值互不相同；
* 在开发中使用switch-case时通常case的情况都是有限的；
* break语句用来在执行完一个case分支后使程序跳出switch语句块；如果没有break，程序会顺序执行到switch结尾；
* default子句是可选的。同时，位置也是灵活的。当没有匹配的case时，执行default语句。
* 利用case的穿透性:如果在匹配成功后没有break，switch会不进行case判断就执行完剩下的语句，例如下题求m月n日是某年的第几天:
```
int m，n
switch(m){
    case 12:
    n += 30;
    case 11:
    n += 31;
    case 10:
    n += 30;
    .......
    case 1:
    break;
}
```

### 5.2. `while`循环的结构


```
初始化条件
while(循环条件){
    循环体;
    迭代部分;
}
```
* while循环和for循环都可以互相转换
* while的初始条件定义在循环条件外，因此是全局可用的

```
Scanner scanner = new Scanner(System.in);
      int randomNumber = (int)(Math.random()*101);
      System.out.println("请输入你猜测的数");
      int i = scanner.nextInt();
      int count = 1;
      while(i != randomNumber){
        System.out.println((i > randomNumber)?"大了":"小了");
        System.out.println("请输入下一个你猜测的数");
        i = scanner.nextInt();
        count++;
      }
      System.out.println("恭喜你猜对了"+",你一共猜了"+count+"次");
//猜数字游戏
```



### 5.3. `do-while`循环的结构


```
初始化条件
do{
    循环体部分
    迭代部分
}while(循环条件)
```
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC03%E7%AB%A0_%E6%B5%81%E7%A8%8B%E6%8E%A7%E5%88%B6%E8%AF%AD%E5%8F%A5/images/image-20220512165558698.png)
* 由于while(循环条件)后置，因此do-while至少都会执行一次
* 循环的三个结构都是可以互相转换的


```
Scanner scanner = new Scanner(System.in);
        int balance = 0;
        int orderNum;
        do{
          System.out.println("请问您需要进行什么操作： 1、存款 2、取款 3、显示余额 4、退出");
          orderNum = scanner.nextInt();
          switch (orderNum) {
            case 1:
            System.out.println("请输入您要存入的金额"); 
            int saveNumber = scanner.nextInt();
            balance += saveNumber; 
            System.out.println("您的余额为"+balance);
              break;
            case 2:
            System.out.println("请输入您取出的金额");
            int outNumber = scanner.nextInt();
            if (outNumber > balance) {
              System.out.println("您的余额不足");
            } else{
              balance -= outNumber;
              System.out.println("您的余额为"+balance);
            }
              break;
            case 3:
            System.out.println("您的存款余额为"+balance);
            break;
            case 4:
            System.out.println("系统已退出，欢迎下次使用");
            break;
            default:
            System.out.println("您输入的指令有误，请重新输入");
              break;
          }
        }while (orderNum != 4);
        scanner.close();
// ATM系统
```
### 5.4 无限循环与嵌套循环

* for循环更适合有明确循环次数时的情况，而while循环适合有明确边界范围的情况，do-while则适合需要进入循环需要先进行一次的情况
* 循环条件都是一个boolean判断式，因此当while(true)/for(;;)时就是一个无限循环

```
Scanner scanner = new Scanner(System.in);
        int positiveNumber = 0;
        int negativeNumber = 0;
        for(;;){
          int input = scanner.nextInt();
          if(input == 0){
            break;
          }else if(input > 0){
            positiveNumber++;
          }else{
            negativeNumber++;
          }
        }
        System.out.println("正数的数量有"+positiveNumber+"个，"+"负数的数量有"+negativeNumber+"个");
// 使用无限循环判断输入的数中正数和负数的数量
```

* 设外层循环次数为m次，内层为n次，则内层循环体实际上需要执行m*n次。
* 在使用嵌套循环时需要控制嵌套的层数在3层之内，否则可读性会很差。


### 5.5 break与continue关键字

* 两个关键字的后面都不能继续跟声明语句

| 关键字 | 使用范围 | 作用 |
| --- | --- | --- |
| break | 循环结构 | 结束/跳出**当前**循环 |
| continue | 循环结构 | 结束/跳出**当次**循环 |



* break语句出现在多层嵌套的语句块中时，可以通过标签指明要终止的是哪一层语句块 

```
label1: {   ……        
	label2:	     {   ……
	label3:			 {   ……
				           break label2;
				           ……
					 }
			     }
			}
```
