# 第二章 变量与运算符

## 1. 关键字
* 被赋予特殊含义，有专门用途的字符串
* 例如HelloWorld中出现的class,public,static,void等
* 所有的关键字都是小写单词
* true，false，null是字面量，但也可以看作关键字

## 2. 标识符
* 可用于我们给自定义变量命名的字符
* 包括26个字母（大小写）  . _ 及 $
* 数字不可以用作开头
* 可以将关键字包含其中
* 长度无限制

### 2.1 一些常用的命名规范
* 包名一般都用小写，例如**java.LANG**
* 类名和接口名一般将单词的首字母大写，例如 **HelloWorld**
* 变量和方法一般首字母小写，多单词时第二个字母开始大写 例如 **age,name,elasticReasearch,getName**
* 所有的字母都大写时，单词之间使用下划线连接，例如 **MAX_VALUE,DEAFULT_CAPACITY**
* 尽量做到见名知意


## 3. 变量
### 3.1 变量的定义
* 不同于py，java是一门强类型语言，在定义变量时需要指明类型
* 三要素：名字、类型、数值
* 声明--> 赋值(第一次的赋值称为初始化)

### 3.2 变量的类型
1. 八种基本类型
* 整形：byte、int、short、long
* 浮点型：float、double
* 布尔型：boolean
* 字符串型：char
2. 引用的数据类型
* 类 class
* 数组 array
* 接口 interface
* 枚举 enum
* 注解 annotation
* 记录 record

### 作用域
* 变量只在离它最近的一对 { }内生效
* 在一个作用域内不能声明现两个同名的变量

## 4 基本数据类型介绍

### 4.1 整型
* byte、short、int、long四个整型变量的本质在于占用存储空间的字节数（带符号）

| Col1 | Col2 | 表数范围(正负) |
| --- | --- | --- |
| byte | 1字节=8bite | 128 |
| short | 2字节 | 2^15 |
| int | 4字节 | 2^31 |
| long | 8字节 | 2^63 |

* long 类型变量在定义时一般在变量结尾加`l或L`
* 一般的整型定义用int


### 4.2 浮点型
* float占用4字节，而double占用8字节，也被称为双精度
* 实际使用中一般都用double型变量，若定义float类型，须在变量结尾以`f或F`结尾
* 在需要更精确数据的金融计算领域，我们需要使用`BigDecimal`类

### 4.3 字符型(char)
* **单个字符**直接用单引号`''`括起来表示字符型变量
* java中的字符型使用unicode编码，因此也可以直接用unicode值来表示字符型常量：`\uXXXX`，其中XXXX是一个十六进制郑曙，例如`\u0023`表示`#`
* Java中还允许使用转义字符`\`来构造一些特殊字符型情况，与py类似。例如`\n`换行符，`\t`制表位，`\\`反斜线等等。
* 且由于用unicode码来表示的原因，char类型也是可以用于运算的，可以被堪为一个数值
* java

### 4.4 布尔型(boolean)
* 不同于py，Java中的bool值只有true和false，不能用其他值替代（1，0等）

## 5.基本数据类型间的运算规则
* 变量类型间的转换有两种:`自动类型提升`和`强制类型转换`
### 5.1 自动类型提升
![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC02%E7%AB%A0_%E5%8F%98%E9%87%8F%E4%B8%8E%E8%BF%90%E7%AE%97%E7%AC%A6/images/image-20220311002543688.png)
1. 当把存储范围小的值（常量值、变量的值、表达式计算的结果值）赋值给了存储范围大的变量时
* 特别的 byte和short之间做运算，结果为int型
* 当在Java中使用大于int范围的整数时需要在整数后添加`L`和`l`的后缀（对应java中将整数默认为int）
* 同样的 `float = 1.3`也无法编译通过，因为Java将1.3默认为double类型，转换为float不满足自动类型提升小转大的规则，须改为`float = 1.3F`
* 为什么不允许变量以数字开头：自洽
```
int 123L = 12
long k = 123L
```
2. 当存储范围小的数据类型与存储范围大的数据类型变量一起混合运算时，会按照其中最大的类型运算。

### 5.2 强制类型转换
* 转换格式
```
数据类型1 变量名 = (数据类型1)被强转数据值;  //()中的数据类型必须<=变量值的数据类型
```
```
int i = (int)3.14;//损失精度

double d = 1.2;
int num = (int)d;//损失精度

int i = 200;
byte b = (byte)i;//溢出
```
* int类转为String类则用到`Interger.tostring()`(使用自身的方法)，`String.Valueof()`方法(使用对象来转变)，使用`""+num`的方式(字符串合并的方式)
* String转int使用Integer.valueof()或者Integer.parseInt()

### 5.3 基础数据类型和String运算
* String属于引用数据类型，使用`""`来表示
* 运算规则：任意八种其他数据与String只能使用`+`进行连接运算，且结果都是String
* 且string没法进行强制类型转换


### 5.4 算数运算符
* 常规：`+  - * / %`
* 自增(减)：放在前面则先运算后取值，放在后面先取值后运算
* 例如：
```
    a = 2；b = ++a // a = 3，b = 3
    a = 2  b = a++ // a = 3，b = 2
```

### 5.5 赋值运算符
* 连续赋值`int a，b； a=b=10`，
* 扩展赋值运算符：`+=,-=,*=,/=,%=`
* 扩展运算符不会改变变量本身的类型，因此在设计整数与短整数的运算时，使用扩展运算符会更加安全，例如
```
short s = 3; 
s = s+2;  //① 编译报错
s += 2;   //② 正常执行
区别在于：
对于第一个表达式 s = s + 2;，这里的"s + 2"是一个整型表达式。所以，当你试图将结果赋值回short类型的s时，编译器会报错，因为它无法自动地将int类型转换为short类型，这可能会导致数据丢失。所以，你需要明确地进行强制类型转换，如 s = (short)(s + 2);，这样代码就能正常运行了。
对于第二个表达式 s += 2;，它可以被看作是一个缩写形式，等价于 s = (short)(s + 2);。“+=”运算符在执行运算前，会自动地将右边的操作数类型转换为左边变量的类型，然后再执行加法，最后赋值。因此，它能够正常地执行并且不会报错。

```

### 5.6 比较运算符
* 常规：`== != > < >= <=`
* `Instance of`判断是否是类对象。当对象是右边类或子类所创建对象时，返回true；否则，返回false。
* 需要注意`String`类型的比较需要`用String.equals()`方法，返回一个`boolea``n`值(引用型数据变量)


### 5.7 逻辑运算符
* `&`和`&&`：表示逻辑且；后者表示短路逻辑，即当左边式子false后就不再计算右边式子
* `|`和`||`:表示逻辑或，后者与上文相似，当左边式子为true后就不再计算右边式子
* `!`表示非关系
* `^`表示异或：当符号左右两边布尔值不同时，结果为true。当两边布尔值相同时，结果为false

### 5.8 条件运算符
* 条件运算符格式：
```
（条件表达式）? 表达式1:表达式2
```
