## 1.Java异常体系

*   throw-catch

### 1.1 Throwable

*   Java抛出的所有throw对象的根父类
*   常用的方法
    *   `public void printStackTrace()` 打印详细信息
    *   `public String getMessage()` 获取原因

### 1.2 Error和Exception

*   Throwable可分为两类：Error和Exception。分别对应着`java.lang.Error`与`java.lang.Exception`两个类。
*   Error：JVM无法解决的问题，例如内存溢出等情况
*   Exception：一般性问题，例如空指针访问，角标越界，文件不存在等等
*   我们此处要处理的对象主要就是Exception类异常

### 1.3.异常发生的阶段

*   分为编译时（checked）与运行时（unchecked）异常

## 2.异常处理

Java中处理异常主要有两种方式：try-catch-finally和throws+异常类型

### 2.1 Try-Catch-Finally

    try{
        //可能会出现异常的代码块
    }
    catch(异常类型1 e1){ //这里的异常类型是对象
        处理操作
    }
    catch(异常类型2 e2){
        处理操作
    }
    ......
    ......
    finally{
        //无论发生异常，一定会执行的代码，此部分也可以省略
    }

![image](https://github.com/luobin7/-java-/raw/main/%E7%AC%AC09%E7%AB%A0_%E5%BC%82%E5%B8%B8%E5%A4%84%E7%90%86/images/image-20220503122722605.png)

*   这里`catch`分支是顺序匹配的，因此如果存在子父类关系，父类要放在下面
*   一般来说，编译时异常是一定要处理的，运行时异常可以等异常抛出时根据异常信息修改。
*   为什么要用`finally`：某些一定要执行的语句，例如**关闭文件、数据库连接、网络连接**等。
*   `try-catch-finally`结构中的语句都是顺序运行的。但注意，一般来说`return`语句都是最后执行的，因此如果`catch`中的是`return`语句，`finally`中的语句会在`catch`中的语句块之前运行
*   try-catch是可以嵌套的

### 2.2 Throws

*   在方法后面直接加异常类型

<!---->

    修饰符 返回值类型 方法名(参数) throws 异常类名1,异常类名2…{   }	

```
public void readFile(String file)  throws FileNotFoundException,IOException {
	...
	// 读文件的操作可能产生FileNotFoundException或IOException类型的异常
	FileInputStream fis = new FileInputStream(file);
    //...
}

```

*   本质上是把声明方法可能会抛出的异常，并把异常的处理了方法的调用者，并需要在调用者处解决异常
*   关系到方法重写的要求：

<!---->

    原本的要求：
    - 方法名一致
    - 形参列表一致
    - 返回值类型一致（基本数据类型 子<=父）
    - 权限修饰符 父>=子，且父类方法在子类中是可见的
    - static，final修饰符修饰的方法不能被重写

<!---->

    此处新增的要求：抛出类型，父>=子（编译时异常）
    -->多态的需求：我们应该能把任何子类对象当作一个父类对象使用
    因此很多抽象方法即使没有方法体也会设置一个throw就是为了预备继承他的子类需要抛出异常

*   throw就像return，当抛出异常后，throw后面的语句便不会执行，并返回一个1异常对象来代替return
*   本质上throw是抛出，而try-catch是处理异常

### 2.3 手动抛出异常对象：throw

*   代码格式：`throw new 异常对象`
*   `throw`语句会导致程序执行流程被改变，`throw`语句是明确抛出一个异常对象，因此它下面的代码将不会执行。
*   如果当前方法没有`try...catch`处理这个异常对象，`throw`语句就会代替`return`语句提前终止当前方法的执行，并返回一个异常对象给调用者。

```
public class ReturnExceptionDemo {
    static void methodA() {
        try {
            System.out.println("进入方法A");
            throw new RuntimeException("制造异常");
        }finally {
            System.out.println("用A方法的finally");
        }
    }

    static void methodB() {
        try {
            System.out.println("进入方法B");
            return;
        } finally {
            System.out.println("调用B方法的finally");
        }
    }
	public static void main(String[] args) {
    	try {
    	    methodA();
   		} catch (Exception e) {
    	  	System.out.println(e.getMessage());
    	}
    	methodB();
  	}
}

```
